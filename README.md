# mlops-wine-quality
Pipelne reproducible de ML para seguimiento y comparaciòn de experimentos con MLflow y Weights &amp; Biases usando Wine Quality

## Integrantes
- Bryan Macas
- Joseph Sangurima

## Herramienta Principal
MLFlow

## Herramienta Alternativa
Weights & Biases (W&B)

## Dataset
Wine Quality - UCI Machine Learning Repository

Licencia del Dataset: Creative Commons Attribution 4.0 International (CC by 4.0)

## Objetivo 
Predecir la cantidad de vino a partir de sus caracteristicas fisioquìmicas 
y gestionar de manera reproducible múltiples experimentos de ML.

## Estructura
- 'data/': Informacion y acceso al dataset
- 'notebooks/': Pipeline Reproducible
- 'results/': métricas y capturas obtenidas durante los experimentos
- 'docs/': referencias y registro de errores encontrados.

## Reproducibilidad
Se utiliza la semilla aleaotria fija: 
'random_state = 42'
